# Archived exploration

This directory preserves the original derived-AQI notebook and formulas for history.
It is not the current pipeline and its saved scores are not validated forecast results.
The original raw CSVs are absent, the notebook requires its old external packages,
and its evaluation has known leakage and reconstruction issues described in
[the evaluation notes](../../docs/evaluation.md).

The current [root notebook](../../AirQuality.ipynb) uses official NAPS PM2.5 and ECCC
weather observations, with reproducible preparation and chronological evaluation.
The old derived-index images under `docs/images/` also belong to this archived analysis.
